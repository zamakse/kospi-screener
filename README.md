# 코스피 연속 음봉 스크리너

평일 20:20(KST)에 GitHub Actions가 코스피 보통주의 일봉을 수집해, 최근 봉부터 음봉(종가 < 시가)이 6개 이상 연속인 종목을 일봉·주봉 기준으로 찾아 `results/`에 저장합니다.

- `results/latest.json` / `results/latest.md`: 가장 최근 결과
- `results/YYYY-MM-DD.json`: 날짜별 기록
- 기준 시세: 네이버 금융 일봉(KRX 정규장 종가, 수정주가). NXT 시간외 체결 미반영
- 조건 변경: `config.json` 을 수정하면 바로 다시 실행됩니다
  - `연속_음봉_최소`: 최근 봉부터 연속 음봉 개수
  - `누적등락률_상한_퍼센트`: 연속 구간 누적 등락률이 이 값 미만인 종목만 (0 = 실제로 내린 종목만, -10 = 10% 넘게 내린 종목만, null = 미적용)
  - `평균거래대금_하한_원`: 최근 20거래일 평균 거래대금이 이 값 미만이면 저유동성으로 분리(표 아래쪽)
  - `구간_봉수` / `구간_음봉_최소`: 누적 음봉 검색. 최근 N봉 중 음봉 K개 이상(연속 아니어도 됨). `구간_음봉_최소` 가 null 이면 꺼짐
- 수동 실행: Actions 탭 > kospi-screener > Run workflow

조건에 맞는 종목을 걸러 주는 도구이며 매매 추천이 아닙니다.
